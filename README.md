# Huffman Coding – Homework

This project contains my homework on Huffman coding.
The program builds a Huffman tree and uses it to encode and decode text.

## Files
- `huffman_homework.py`: Python file containing all the code for the assignment.

## How to run the program
1. Open the file `huffman_homework.py` in VS Code.
2. Click the Run button.
3. The results are displayed in the terminal.

The program runs correctly from start to end.
